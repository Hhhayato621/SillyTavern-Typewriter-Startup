# 打字机 · 载入动画扩展 1.0.2

黑色复古打字机、做旧纸张与逐字打出的 **SillyTavern**。这是独立的载入动画扩展，不包含聊天主题包。

## 手机与电脑安装

在酒馆「扩展 → 安装扩展程序」中粘贴：

```text
https://github.com/Hhhayato621/SillyTavern-Typewriter-Startup
```

安装后刷新酒馆，再展开「扩展 → 打字机 · 载入动画」。服务端需要允许第三方扩展，并能访问 GitHub。手机和电脑的安装方式相同；不需要导入 ZIP，也不需要改动酒馆源文件。

如果没有安装扩展权限，请联系你使用的酒馆服务器管理员安装。最低支持 SillyTavern 1.18.0。

## 手动安装

将本仓库下载解压后，把整个文件夹放进酒馆的 `public/scripts/extensions/third-party/`。确认文件夹内直接是 `manifest.json`，然后刷新。无需改动 index.html 或 script.js。

## 使用与卸载

「扩展」里展开「打字机 · 载入动画」，可以启用/停用并预览。开关在刷新后生效。完整禁用/删除通过酒馆扩展管理器进行，完成后刷新；手动安装的也可删除该文件夹后刷新。

## 加载阶段的限制

扩展只能在酒馆开始加载第三方扩展后执行；在此之前，原生 Logo 可能短暂出现。初始化很快时，动画可能尚未打完就进入主页，扩展不会人为拖慢启动。完全替换最早一帧仍需要之前的源文件补丁，它是另一种安装方式。

兼容 SillyTavern 1.18.x 与 1.19.x 共用的原生初始加载器和 manifest activate 生命周期。1.18 已核对官方源码接口；未在完整 1.18 服务端上进行实机测试。1.18 以前的版本不在当前支持范围。动画只装饰 #loader.splash-screen，不接管原生加载完成逻辑，不修改生成过程中的加载器。

## 性能与隐私

素材随包提供，无外部 CDN、无第三方统计、不读取对话、不向第三方发送数据。动画只在初始化或手动预览时存在；预览可以随时关闭，15 秒自动退出。支持系统减少动态效果设置。资源总计约 355 KB，包含本地 WebP 图片和英文字体，不携带聊天主题的大型中文字体。

原图与动画：本主题项目原创素材。Special Elite 字体许可见 SpecialElite-LICENSE.txt。代码可自由修改和分享；字体仍按其原许可分发。

若你的酒馆已安装之前的源文件补丁，停用本扩展不会自动卸载该补丁。两者是独立安装方式；本包不会覆盖你原有的酒馆文件。
